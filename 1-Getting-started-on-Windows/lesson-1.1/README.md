# Lesson 1.1: Visual Studio & The MSVC Command Line

## The Goal
Master the standard Windows environment and understand how it works under the hood.

---

## Overview
In this lesson, you will:
- learn how to configure a professional Windows development environment
- dissect how Visual Studio manages code under the hood
- drop down into the command line to compile a C++ program manually using the raw Microsoft compiler.


## Table of Contents
1. [Installation & Setup](1-install.md)
2. [Your First Program: IDE vs. CLI Workflows](2-first-program.md)

## Expected Deliverable
By the end of this lesson, you will have a successfully compiled "Hello Windows" program built via two entirely different methods:
*   The Visual Studio IDE using the **Ctrl + F5** ("Start Without Debugging") shortcut.
*   The Windows command line using the raw MSVC toolchain tools.
